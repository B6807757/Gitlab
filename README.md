# Solar Panel Efficiency Tracker

โปรแกรมคำนวณกำลังไฟฟ้าและประสิทธิภาพของแผงโซลาร์เซลล์จากค่าที่วัดได้ พร้อมประมาณกำลังที่ควรผลิตตามความเข้มแสงและอุณหภูมิของแผง

## วิธีใช้งาน

รันด้วย Python 3:

```bash
python electrical.py
```

กรอกค่ารังสีแสงอาทิตย์ (W/m^2), อุณหภูมิแผง (C), พื้นที่แผง (m^2), แรงดัน (V), กระแส (A) และกำลังพิกัดของแผง ณ STC (W) ตามลำดับ

ค่าสัมประสิทธิ์อุณหภูมิกำลังมีค่าเริ่มต้นเป็น `-0.004` ต่อองศาเซลเซียส หรือกำลังลดลง 0.4% ต่อ 1 C ที่สูงกว่า 25 C หากต้องการใช้ค่าอื่น ให้กรอกเป็นอัตราส่วนต่อองศา เช่น `-0.0035` สำหรับ -0.35%/C

โปรแกรมแสดงกำลังที่วัดได้, ประสิทธิภาพการแปลงพลังงาน, กำลังที่คาดหมายหลังปรับตามรังสีและอุณหภูมิ และ performance ratio เทียบกับกำลังที่คาดหมาย

## ข้อจำกัด

ค่าต้องกรอกด้วยตนเอง โปรแกรมนี้ยังไม่เชื่อมต่อเซนเซอร์หรือเก็บข้อมูลแบบเรียลไทม์ ประสิทธิภาพคำนวณจากกำลังไฟฟ้าขาออกหารด้วยกำลังแสงที่ตกกระทบบนพื้นที่แผง และค่าประมาณกำลังใช้แบบจำลองเชิงเส้นจากกำลังพิกัดที่ STC
